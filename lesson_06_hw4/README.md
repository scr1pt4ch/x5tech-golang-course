# Сервис заказов (Дз4)

Перенёс однофайловый сервис заказов в несколько пакетов. Программа работает так же, как раньше: создаёт один заказ и печатает адрес, на котором работал бы сервер.

## Как запустить

Из папки, где лежит `go.mod`:

```bash
go run ./cmd/orders
```

Вывод:

```
сервис слушал бы :8080, создан заказ: {ID:1 Customer:Покупатель Status:new}
```

## Настройка

Адрес задаётся переменной окружения `HTTP_ADDR`. Если она не задана, используется `:8080`.

```bash
HTTP_ADDR=:9090 go run ./cmd/orders
```

Вывод:

```
сервис слушал бы :9090, создан заказ: {ID:1 Customer:Покупатель Status:new}
```

ID каждый раз равен 1, потому что при новом запуске хранилище снова пустое.

## Пакеты

- `cmd/orders` - точка входа. Здесь читается настройка и создаются все объекты: хранилище, сервис и обработчик.
- `internal/config` - читает `HTTP_ADDR` и подставляет `:8080`, если переменная пустая.
- `internal/model` - структура заказа `Order`.
- `internal/repository` - хранилище `Memory`, которое держит заказы в map.
- `internal/service` - логика создания заказа: проверка имени клиента и выдача ID. Здесь же интерфейс `Repository`, поэтому сервис не зависит от конкретного хранилища.
- `internal/handler` - обработчик, который вызывает сервис. Ему нужен только метод `Create`, поэтому он описан маленьким интерфейсом `OrderCreator`.
