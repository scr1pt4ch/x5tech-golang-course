# Starter СР-1

## Задание

Реализуйте анализатор продаж:

```go
func AnalyzeSales(sales []Sale) Report
```

Для каждой продажи известны товар, категория, количество, цена за единицу в
копейках и признак отмены. Функция должна:

- рассчитать общую выручку в копейках;
- посчитать число проданных единиц;
- собрать выручку по категориям;
- определить самый продаваемый товар по количеству единиц;
- посчитать некорректные записи;
- не изменять исходный срез.

## Правила

- Запись некорректна, если товар или категория пусты, количество не положительно
  либо цена не положительна.
- Некорректная запись не участвует в остальных расчётах и увеличивает
  `InvalidSales`.
- Отменённая продажа пропускается раньше валидации: она не входит в отчёт и не
  считается некорректной.
- При равном количестве проданных единиц лидером становится лексикографически
  меньшее название товара.
- Для пустого входа возвращается отчёт с нулевыми значениями и созданной пустой
  `RevenueByCategory`.
- Используйте только структуры, срезы, `map`, условия, циклы и функции.
  Интерфейсы, горутины и сторонние библиотеки не нужны.

## Краткое описание алгоритма

Функция совершает один проход по всему срезу продаж.
Невалидные записи инкрементируют счётчик InvalidSales и дальше не учитываются.
Для валидной записи считается выручка и добавляется к общему результату выручки и выручке её категории.
Количество добавляется к UnitsSold и к счётчику этого товара.
После прохода выбирается товар с наибольшим числом единиц, при равенстве лексикографически меньшее среди таких значений.

Алгоритм линейный по времени (O(n), где n - число продаж).
По памяти O(n) в худшем случае.
