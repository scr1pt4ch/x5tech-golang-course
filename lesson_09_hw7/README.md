# Сервис заказов - занятие 9

HTTP API заказов со Swagger-документацией. Данные хранятся в памяти и пропадают после перезапуска. Требуется Go 1.22+.

## Запуск

```bash
go mod download
go generate ./...
go run ./cmd/orders
```

Сервер: `127.0.0.1:8080`, Swagger UI: http://127.0.0.1:8080/swagger/index.html.
Запросы для ручной проверки - в `requests.http`.

## API

| Метод | Путь | Ответ |
|---|---|---|
| GET | `/api/v1/status` | `200` |
| POST | `/api/v1/orders` | `201` + `Location` |
| GET | `/api/v1/orders/{id}` | `200` |
| GET | `/api/v1/orders` | `200`, массив заказов |

Ошибки приходят в формате `{"error": "...", "code": "..."}`.

## Список заказов

- Сортировка по `id` по возрастанию. Пустой список и страница за концом - `[]`.
- `limit` - от 1 до 100, по умолчанию 20. `offset` - целое `>= 0`, по умолчанию 0.
- Числа принимаются только из десятичных цифр. Неверное, пустое, повторное или неизвестное значение - `400 INVALID_QUERY`.
- Огромный `offset` возвращает `[]` без паники: сумма `offset + limit` не вычисляется.
